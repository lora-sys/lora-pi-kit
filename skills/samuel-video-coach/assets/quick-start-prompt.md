# Quick Start Prompts

## 只给主题

```text
使用 samuel-video-coach，默认零基础手把手模式。

我要拍：［主题］。
我还没有整理素材。请先基于合理假设给我一个今天能开拍的版本，所有不确定事实标为【待补证据】。不要只给专业术语。逐句告诉我说什么，逐镜头告诉我拍什么、手机放哪里、拍几秒、为什么这样拍、拍坏了怎么替代。标出 AI 视频过渡的首尾锚点和 Prompt，以及共鸣、评论区和下一期设计。
```

## 有真实项目

```text
使用 samuel-video-coach。

主题：［主题］
我真实做了：［过程］
最终结果：［结果］
失败或限制：［失败/代价］
已有素材：［录屏、截图、数据、产品、照片］
平台：［平台］
目标时长：［时长］
是否露脸：［是/否］
目标观众：［人群］

请按 Samuel-inspired 的结果先行、人的故事、真实实验、具体证据、反转和个人判断来做。先给我今天的拍摄行动地图，再给完整提词器脚本、手把手分镜、AI 转场、评论讨论和剪辑顺序。
```

## 改造已有脚本

```text
使用 samuel-video-coach 检查并重写下面的脚本。

要求：
1. 判断它是否变成了工具说明书；
2. 改成结果先行的人物故事；
3. 不编造实验和数据；
4. 补足可见证据；
5. 加入真实反转和个人判断；
6. 给零基础可执行的分镜；
7. 标出 AI 视频只应出现在哪里；
8. 设计一个存在两个合理立场的评论问题。

原稿：
［粘贴脚本］
```
