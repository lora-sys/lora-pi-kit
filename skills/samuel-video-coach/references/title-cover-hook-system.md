# Title, Cover, and Hook System

## 1. Samuel-inspired 标题的核心

标题优先表达：

`创作者行动 + 普通人结果/代价 + 信息缺口`

例子结构：

- 我用 X 做了 Y，结果 Z。
- 我花了 X 天/元测试 Y，它真的值吗？
- 千万别让 X 知道，我开始用 Y 做 Z。
- 一个不会 X 的人，用 AI 做出了 Y？
- 我把 X 变成 Y，工作方式彻底变了。

不要只写：

- 某某工具介绍；
- 某模型功能大全；
- AI Agent 技术解析；
- 最新产品评测。

## 2. 五类标题

### 结果型

强调已完成的变化。

`我把手机变成了 AI 指挥中心`

### 冲突型

强调代价、风险或不应该发生的事。

`它写完了产品，我却不敢上线`

### 身份型

挑战职业、年龄、技能或生活身份。

`作为程序员，我第一次怕的不是 AI 写不好`

### 数字型

用具体时间、成本、数量或规模。

`我用 7 天和 3 个 Agent，做了一次无人开发实验`

### 小白收益型

明确低门槛和可复现结果。

`0 基础，用 AI 做出第一个可用产品`

## 3. 封面

封面只回答一个问题：“为什么停下来？”

### 元素

- 创作者表情或身体动作；
- 最强证据画面；
- 4–10 字大字；
- 一个对立关系。

### 对立例子

- 成品页面 / 红色报错；
- 旅行海景 / 工作消息；
- 100 个 Agent / 一个人；
- 3 小时 / 3 天；
- 免费 / 隐私代价。

### 不要

- 10 个图标；
- 大段文字；
- 完整标题重复；
- 小到看不见的代码；
- 与视频无关的惊恐表情。

## 4. 前三秒 Hook

Hook 不是大喊，而是展示信息缺口。

至少包含两个：

- 不寻常行动；
- 可见结果；
- 具体数字；
- 风险；
- 身份矛盾；
- 未解问题。

### 结果 Hook

`“它真的把整个页面做出来了。”` + 成品可点击画面。

### 冲突 Hook

`“它通过了所有测试，也差点删掉我的数据。”` + 绿色测试与红色错误对切。

### 身份 Hook

`“作为开发者，我第一次担心的不是 AI 不会写，而是它写得太快。”` + 正面近景。

## 5. 0–10 秒画面节奏

建议：

1. 最强结果 1–2 秒；
2. 冲突或失败 1–2 秒；
3. 人物反应 1–2 秒；
4. 中心问题 3–5 秒。

只有画面变化有意义时才切，不要为了快而乱切。

## 6. 标题诚实检查

- 标题里的数字有证据吗？
- 标题里的结果真的发生了吗？
- “0 基础”是否真的不要求隐藏前置知识？
- “几分钟学会”是视频时长还是实际学习时间？必须说清。
- 标题疑问是否在视频中被回答？
