# Evaluation Rubric

Score each category from 0 to 3.

1. Narrative: problem-to-solution flow and earned reveal.
2. Content-specific visuals: diagrams materially improve understanding.
3. SVG quality: readable, semantic, accessible, uncluttered.
4. Motion: restrained and communicates state, order, or direction.
5. Design: coherent dark editorial system, not a generic template.
6. Technical quality: standalone, keyboard-friendly, responsive, reduced-motion ready.
7. Truthfulness: facts, models, assumptions, and recommendations are distinguished.

Passing target: 17 / 21.
