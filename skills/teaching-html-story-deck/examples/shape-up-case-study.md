# Shape Up Case Study

## Input

Create a teaching HTML for a Shape Up-inspired Agent Skill.

Requirements:

- start from why AI projects become easier to start but still fail;
- explain use cases and trigger boundaries;
- show the principle and core method;
- show data flow and a core module mind map;
- show multi-Agent architecture;
- show an AI Company OS before/after example;
- include a Hill Chart;
- reveal the Skill on the final page;
- use a refined dark developer-product aesthetic;
- output one standalone HTML file.

## Narrative

```text
AI execution is cheap
→ judgment is the bottleneck
→ projects need a pre-coding gate
→ define trigger boundaries
→ shape the project
→ create a bounded bet
→ give all Agents one Brief
→ demand evidence
→ Ship / Reshape / Kill
→ reveal the Skill
```

## Visual mapping

| Concept | Visual |
|---|---|
| Failure chain | horizontal flow |
| Trigger boundary | 2×2 matrix |
| Shaping process | data-flow SVG |
| Skill responsibilities | radial mind map |
| Multi-Agent permissions | architecture SVG |
| Scope reduction | before/after |
| Project uncertainty | Hill Chart |
| Final product | install / invocation panel |

## Key decision

The Skill is not introduced until the final page. This lets the audience understand the problem and method before seeing the implementation.
